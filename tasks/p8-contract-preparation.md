## 基线可复用接口事实

| 来源 | 已核对契约 | P8 含义 |
|---|---|---|
| include/mini_camera_raw/image_buffer.h and image_metadata.h | 拥有 uint16/float 存储，显式行布局/颜色/传递/范围，可变样本接口仍存在 | 编辑源不可变须有所有权契约，不能从容器推定 |
| raw_decoder.h, white_balance.h, demosaic.h | 解码返回自有原始图与元数据，白平衡位于双线性去马赛克前 | 后续白平衡控件影响上游复用，不能默认仅 RGB 缓存足够 |
| tone.h; src/tone.cpp | 曝光返回独立线性 sRGB，EV 有限且在 [-20,20] 区间，无裁剪 | 可复用基本操作，未提供持久会话或滑块策略 |
| color_transform.h | 相机域裁剪在矩阵前生成输出副本，上限1，保留负值及源 | 必须区别于未裁剪工作数据和重建 |
| display_encode.h; png_writer.h | 编码接受线性或影调后工作 sRGB，输出裁剪量化为 RGB16；写入拒绝覆盖 | 编码可直接接收无肩部线性输出；内存界面显示仍须独立确认契约 |
| apps/render_pipeline.cpp; src/tone.cpp | 协调器始终调用影调函数，强度0保持数值但仍标记影调后状态 | 不把强度0等同省略算子；既有协调器并非已批准未来正式路径 |
| apps/mini_camera_raw.cpp:120–138 | RAW/Bayer 临时对象在单次渲染/编码/写入前离开作用域 | 当前 CLI 生命周期不等于持久会话、请求排序或预览缓存 |

以上为本地源码事实，不是新 API 提案、新运行验证或外部库保证；本检查点不修改头文件或生产代码。
